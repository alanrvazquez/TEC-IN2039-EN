Creating Your Personal Website with Quarto

From GitHub to a professional online CV

Author
Affiliation

Alan R. Vazquez

Department of Industrial Engineering

1 Introduction

In this activity, you will create and publish your own personal professional website.

The goal is not to become a web developer. Instead, you will learn a simple workflow that allows you to create and maintain a professional website using tools that are widely used for data science, research, and technical work.

By the end of this activity, you will have a website that can contain:

  • Your professional profile
  • Your CV
  • Your education and work experience
  • Your skills
  • Links to projects
  • Links to your GitHub repositories
  • Links to other professional profiles
  • Additional pages that you may add in the future

Your website will be publicly available on the Internet through GitHub Pages.

The basic workflow will be:

GitHub account
      ↓
GitHub repository
      ↓
GitHub Desktop
      ↓
R + RStudio
      ↓
Quarto website
      ↓
GitHub
      ↓
GitHub Pages
      ↓
Your personal website
TipWhat you will accomplish

At the end of this activity, you should be able to create, modify, and publish a simple personal website without needing to know HTML or CSS.

2 Before You Start

You will need to install several free tools.

2.1 Tools

You will use:

  1. GitHub — to store your website files online.
  2. GitHub Desktop — to synchronize files between your computer and GitHub.
  3. R — the programming language used by RStudio.
  4. RStudio — the environment where you will create and edit your Quarto website.
  5. Quarto — the system that transforms your .qmd files into a website.
WarningImportant

You will need an Internet connection when creating your GitHub account, creating the repository, and publishing the website.

You will also need to use an email address that you can access because GitHub may ask you to verify your account.

3 Part 1 — Create a GitHub Account

3.1 What is GitHub?

GitHub is an online platform for storing and managing files using Git.

For this activity, you can think of GitHub as a place where you will store the source files that make up your website.

GitHub will also allow you to keep a history of the changes you make to your website.

You do not need to learn Git commands for this activity. We will use GitHub Desktop to make the process easier.

3.2 Create your account

Go to:

https://github.com/

Select Sign up and create your account.

Choose your GitHub username carefully.

Your username will appear in your website address.

For example:

github.com/alanrvazquez

could potentially lead to a website such as:

https://alanrvazquez.github.io/
TipChoosing your username

Try to choose a professional username.

For example:

johndoe
john-smith
johnsmith

are generally better choices for a professional website than usernames such as:

john12345
cooldude2026
xXjohnXx

You will potentially use this username on your CV, job applications, and professional profiles.

4 Part 2 — Install GitHub Desktop

4.1 What is GitHub Desktop?

GitHub Desktop provides a graphical interface for working with GitHub.

Instead of typing Git commands into a terminal, you can use buttons and menus to:

  • Download repositories
  • Save changes
  • Create commits
  • Upload changes to GitHub
  • Download changes from GitHub

GitHub describes Desktop as a graphical interface that simplifies common Git operations. (GitHub Docs)

Download GitHub Desktop from:

https://desktop.github.com/

Install the application following the instructions for your operating system.

4.2 Sign in

Open GitHub Desktop and sign in using the GitHub account you created in Part 1.

Make sure that you sign in with the same GitHub account that you will use for your website.

5 Part 3 — Create Your First Repository

5.1 What is a repository?

A repository, or repo, is a folder that is managed by Git.

For this project, your repository will contain all the files needed to create your website.

For example:

my-personal-website/
│
├── _quarto.yml
├── index.qmd
├── cv.qmd
├── projects.qmd
├── images/
└── ...

The repository will exist both:

  • On your computer
  • On GitHub

GitHub Desktop helps keep these two versions synchronized.

5.2 Create the repository

Open GitHub Desktop.

Select:

File → New repository

Enter:

Name

my-personal-website

You may use another name if your instructor specifies one.

For example:

alan-personal-website

Select a location on your computer where you want to save the repository.

For example:

Documents/GitHub/

Make sure that Initialize this repository with a README is selected.

Then select:

Create repository

5.3 Publish the repository

After creating the repository, GitHub Desktop will show the new repository.

Select:

Publish repository

Make sure the repository is published to your GitHub account.

WarningDo not confuse the repository with the website

At this point, you have created a GitHub repository.

You have not created your website yet.

The repository is simply the place where your website’s files will live.

6 Part 4 — Install R and RStudio

6.1 Install R

Download R from:

https://cran.r-project.org/

Choose the version appropriate for your operating system and follow the installation instructions.

6.2 Install RStudio

RStudio is an Integrated Development Environment (IDE) that makes it easier to work with R and Quarto.

Download RStudio from:

https://posit.co/download/rstudio-desktop/

Install RStudio after installing R.

WarningImportant

Install R first and RStudio second.

R is the programming language.

RStudio is the application that provides an interface for working with R.

7 Part 5 — Install Quarto

7.1 What is Quarto?

Quarto is a publishing system that allows you to create documents, presentations, reports, books, and websites using plain-text files.

A Quarto website is usually created from files with the extension:

.qmd

For example:

index.qmd
cv.qmd
projects.qmd

Quarto converts these files into HTML pages that can be displayed in a web browser.

Quarto websites can also include navigation, different pages, images, links, code, tables, and other content. (Quarto)

7.2 Install Quarto

Download Quarto from:

https://quarto.org/docs/get-started/

Install the version appropriate for your operating system.

After installation, restart RStudio.

TipCheck your installation

Open RStudio and create a new Quarto document.

If you can create and render a Quarto document, your installation is probably working correctly.

8 Part 6 — Create Your Quarto Website

Now we will create the actual website.

8.1 Create a new Quarto project

Open RStudio.

Select:

File → New Project → New Directory → Quarto Website

You should see a window similar to the following:

  • Project type: Quarto Website
  • Directory name: my-personal-website
  • Create project as subdirectory of: choose your GitHub repository folder

For example:

Documents/GitHub/my-personal-website
WarningBe careful with the location

Your Quarto website should be created inside the GitHub repository folder.

You want the following relationship:

GitHub repository
        │
        ├── _quarto.yml
        ├── index.qmd
        ├── cv.qmd
        └── projects.qmd

Do not accidentally create a separate folder somewhere else on your computer.

9 Part 7 — Understand the Website Files

After creating the Quarto website, you will see several files.

The most important ones are:

_quarto.yml
index.qmd

9.1 _quarto.yml

This file contains the configuration of your website.

For example:

project:
  type: website

website:
  title: "John Smith"
  
format:
  html:
    theme: cosmo

You can think of _quarto.yml as the control panel for your website.

It determines things such as:

  • Website title
  • Navigation
  • Theme
  • Pages
  • Appearance
  • Other website settings

9.2 index.qmd

This is the homepage of your website.

The filename:

index.qmd

is important because it becomes the main page of your website.

For example, your homepage could contain:

---
title: "John Smith"
---

# Welcome!

I am a student of Industrial Engineering interested in
data analytics, process improvement, and decision making.

## About me

I am currently studying Industrial Engineering at
Tecnológico de Monterrey.

## What I do

- Data analysis
- Process improvement
- Data visualization
- Operations research

You can write your content using simple Markdown.

Create another Quarto document:

projects.qmd

title: "Projects"

As you complete projects during your degree, you can continue adding them to this page.

12 Part 10 — Create Website Navigation

Now we will connect the pages.

Open:

_quarto.yml

and modify it to include navigation.

For example:

project:
  type: website

website:
  title: "John Smith"
  
  navbar:
    left:
      - href: index.qmd
        text: Home
      - href: cv.qmd
        text: CV
      - href: projects.qmd
        text: Projects

format:
  html:
    theme: cosmo

Your website will now have a navigation bar similar to:

John Smith     Home     CV     Projects

Quarto supports several navigation structures, including top navigation and side navigation. (Quarto)

15 Part 13 — Preview Your Website

Before publishing your website, you should check how it looks.

Open:

index.qmd

in RStudio.

Select:

Render

Quarto will generate the HTML version of your website and open a preview.

Check:

  • Are the navigation links correct?
  • Are there spelling mistakes?

Quarto is designed so that you can preview your website locally before publishing it. (Quarto)

16 Part 14 — Save Your Changes with GitHub Desktop

Now we need to send your website files to GitHub.

Open GitHub Desktop.

You should see a list of the files that you have changed.

For example:

_quarto.yml
index.qmd
cv.qmd
projects.qmd

16.1 Commit your changes

At the bottom of GitHub Desktop, write a short description of your changes.

For example:

Create personal website

Select:

Commit to main

A commit is essentially a saved version of your work.

16.2 Push your changes

After committing, select:

Push origin

This sends your changes from your computer to GitHub.

The workflow is:

Edit files
     ↓
Save files
     ↓
GitHub Desktop
     ↓
Commit
     ↓
Push
     ↓
GitHub

17 Part 15 — Publish Your Website with GitHub Pages

Now we will make the website publicly available.

GitHub Pages is a hosting service that publishes content from a GitHub repository as a website. (GitHub Docs)

There are several ways to publish a Quarto website to GitHub Pages.

For this activity, we will use the Quarto gh-pages publishing method because it is relatively simple for students.

17.1 First, make sure your website works

Before publishing:

  1. Render the website in RStudio.
  2. Check all pages.
  3. Save your files.
  4. Commit your changes using GitHub Desktop.
  5. Push your changes to GitHub.

17.2 Publish with Quarto

Open the Terminal in RStudio.

You can usually find it under:

Tools → Terminal → New Terminal

Make sure that the terminal is located inside your website repository.

Then run:

quarto publish gh-pages

Quarto will render your website and publish it to a special branch called:

gh-pages

The Quarto documentation describes quarto publish gh-pages as a way to publish a locally rendered website to GitHub Pages. (Quarto)

WarningDo not use the gh-pages branch for editing

Your source files should remain in your normal working branch, usually:

main

The gh-pages branch contains the published version of your website.

Continue editing your .qmd files in your normal branch.

18 Part 16 — Find Your Website

After publishing, your website will normally have an address similar to:

https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/

For example:

https://johnsmith.github.io/my-personal-website/

The exact address depends on your GitHub username and repository name.

GitHub Pages also provides a Visit site link in the repository’s Pages settings. (GitHub)

TipYour first publication

The first publication can take a few minutes.

If the website does not appear immediately, wait a little and refresh the page.

25 Part 23 — Troubleshooting

25.1 My Quarto website does not render

Check:

  • Is Quarto installed?
  • Is R installed?
  • Is RStudio updated?
  • Are there errors in _quarto.yml?
  • Are the filenames correct?
  • Are you working inside the correct repository?

Try rendering again.

25.2 My image does not appear

Check that the image is inside your repository.

For example:

my-personal-website/
│
├── index.qmd
└── images/
    └── profile.jpg

Then use:

![](images/profile.jpg)

Check the capitalization of the filename.

For example:

profile.jpg

and

Profile.jpg

are not necessarily treated as the same filename.

25.3 My page does not appear in the navigation bar

Check _quarto.yml.

For example:

navbar:
  left:
    - href: index.qmd
      text: Home
    - href: cv.qmd
      text: CV
    - href: projects.qmd
      text: Projects

Make sure that the .qmd filename exactly matches the filename in your folder.

25.4 My website is not updating

First check that you:

  1. Saved your changes.
  2. Committed the changes in GitHub Desktop.
  3. Pushed the changes to GitHub.
  4. Published the website again if necessary.

Also remember that GitHub Pages may take a short amount of time to deploy a new version.

25.5 GitHub Pages shows an error

Go to your GitHub repository and open:

Settings → Pages

Check the publishing configuration and deployment status.

GitHub provides the Pages settings under the repository’s Settings → Pages area. (GitHub Docs)
