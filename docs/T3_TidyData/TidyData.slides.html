Data Science Workflow

  • Every data science project involves importing, tidying, transforming, visualizing, and modeling data.
  • tidyr focuses on the tidy part — making your data easy to work with.

Why Focus on Tidy Data?

“Tidy datasets are easy to manipulate, model, and visualize.” — Hadley Wickham

  • Tidy data principles make R tools work together smoothly.
  • Each tidy dataset is like a well-organized spreadsheet.
  • Most errors in analysis happen before modeling — during data wrangling.

The Tidyverse

The tidyverse is a collection of R packages designed for data science.

Package Purpose

dplyr Manipulate and summarize data

A Realistic Workflow

  1. Import: Bring raw data into R.
  2. Tidy: Reshape into a consistent format.
  3. Transform: Create new variables and summaries.
  4. Visualize: Explore patterns.
  5. Model: Fit statistical or machine learning models.
  6. Communicate: Share insights clearly.

Where Does tidyr Fit?

  • tidyr connects raw data to analysis-ready data.
  • Often used before dplyr or ggplot2.

Data Messiness Example

# A tibble: 3 × 3
  store jan_sales feb_sales
  <chr>     <dbl>     <dbl>
1 A           100       110
2 B            80        95
3 C           120       130

Problem: Not Tidy!

  • Variable names (jan_sales, feb_sales) store values (months).
  • Each column should represent a variable, not a combination of variables.
  • Each row should represent a single observation.

Part 2: Introduction to Tidy Data

Goal: Learn what “tidy data” means and why it’s crucial for analysis and visualization.

What Is Tidy Data?

Note

In a tidy dataset: 1. Each variable forms a column.
2. Each observation forms a row.
3. Each value forms a cell.

This simple structure makes it easier to analyze, visualize, and model your data using R.

Example: Untidy Data

# A tibble: 3 × 3
  name    math english
  <chr>  <dbl>   <dbl>
1 Ana       90      88
2 Luis      80      95
3 Carmen    85      92

Why is this Untidy?

  • Each column (math, english) represents both a variable and a category.

  • The structure hides the relationship between subject and score.

  • Harder to summarize or visualize.

The tidy version

# A tibble: 6 × 3
  name   subject score
  <chr>  <chr>   <dbl>
1 Ana    math       90
2 Ana    english    88
3 Luis   math       80
4 Luis   english    95
5 Carmen math       85
6 Carmen english    92

Why tidy data matters

  • Every observation is self-contained in a single row.

  • Makes it easy to:

    • Group and summarize with dplyr

    • Plot with ggplot2

Another Example: Messy Survey Data

# A tibble: 3 × 3
     id q1_morning q1_evening

tidy version

Wide Vs Long Data

Why tidyr?

Note

tidyr helps you reshape, separate, combine, and complete data so that: - Each variable is a column - Each observation is a row - Each value is a cell

In short: tidyr helps you tidy up messy data structures.

tidyr and the Tidyverse

  • tidyr works seamlessly with dplyr.
  • While dplyr focuses on data manipulation, tidyr focuses on data structure.
  • Together, they make your data clean and consistent before visualization or modeling.

Example Dataset: production_data

# A tibble: 3 × 3
  factory jan_output feb_output
  <chr>        <dbl>      <dbl>
1 A              120        130
2 B              150        160
3 C              100         90

pivot_longer()

Transform columns into rows (convert from wide to long format).

# A tibble: 6 × 3
  factory month      output
  <chr>   <chr>       <dbl>
1 A       jan_output    120
2 A       feb_output    130
3 B       jan_output    150
4 B       feb_output    160
5 C       jan_output    100
6 C       feb_output     90

pivot_wider()

Transform rows into columns (convert from long to wide format).

# A tibble: 3 × 3
  factory jan_output feb_output
  <chr>        <dbl>      <dbl>
1 A              120        130
2 B              150        160
3 C              100         90

separate()

Split one column into multiple columns.

# A tibble: 6 × 4
  factory month variable output
  <chr>   <chr> <chr>     <dbl>
1 A       jan   output      120
2 A       feb   output      130
3 B       jan   output      150
4 B       feb   output      160
5 C       jan   output      100
6 C       feb   output       90

unite()

Combine multiple columns into a single column.

# A tibble: 6 × 3
  factory month_variable output
  <chr>   <chr>           <dbl>
1 A       jan_output        120
2 A       feb_output        130
3 B       jan_output        150
4 B       feb_output        160
5 C       jan_output        100
6 C       feb_output         90

nest()

Create nested data frames for grouped data — useful for modeling or list-columns.

# A tibble: 3 × 2
# Groups:   factory [3]
  factory data            
  <chr>   <list>          
1 A       <tibble [2 × 2]>
2 B       <tibble [2 × 2]>
3 C       <tibble [2 × 2]>

unnest()

Expand a nested data frame back into regular rows.

# A tibble: 6 × 3
# Groups:   factory [3]
  factory month      output
  <chr>   <chr>       <dbl>
1 A       jan_output    120
2 A       feb_output    130
3 B       jan_output    150
4 B       feb_output    160
5 C       jan_output    100
6 C       feb_output     90

complete()

Ensure all combinations of variables exist, filling in missing observations.

# A tibble: 4 × 3
  factory month output
  <chr>   <chr>  <dbl>
1 A       feb      130
2 A       jan      120
3 B       feb       NA
4 B       jan      150

fill()

Fill missing values with the most recent non-missing value.

# A tibble: 4 × 3
  factory month output
  <chr>   <chr>  <dbl>
1 A       feb      130
2 A       jan      120
3 B       feb      120
4 B       jan      150

Why Tidy Data Matters in Decision Making

Note

Tidy data ensures: - Easier manipulation using dplyr - Seamless visualization with ggplot2 - Smooth modeling and reporting in R

Bottom line:
Tidy data is not just a rule — it’s a way to think about data clearly and communicate insights effectively.

The “Messy Data” Reality

Many industrial datasets are not tidy.
Examples:

Dataset Problem
Production reports in Excel Values stored in column names
Maintenance logs Multiple variables combined in one column
Quality inspections Missing or inconsistent codes

Our task: Use tidyr to fix these structures before analysis.

From Messy to Tidy: A Typical Workflow

  1. Import raw data (e.g., CSV, Excel, SQL)
  2. Identify problems in structure
  3. Reshape or clean with tidyr
  4. Manipulate with dplyr
  5. Visualize with ggplot2
  6. Communicate insights with Quarto

Why Visualization Loves Tidy Data

Note

Every ggplot requires data in long format:

x-axis: variable (e.g., month)

y-axis: measurement (e.g., output)

color/fill: grouping variable (e.g., factory)

That’s why pivot_longer() is your best friend before plotting.

Advantages of Tidy Data

  • one set of consistent tools for different datasets
  • easier for automation and iteration

“Tidy data is the bridge between raw numbers and clear insight.” — Hadley Wickham

  • To work with messy data, every time you need to switch to different gears
  • learn new tools that just works for that specific dataset
  • It’s much more pleasant to work with tidy data, help you to build a good taste of data analysis
  • spent less fighting with different tools, focus more on data analysis bc one set of consistent tools
  • the {tidyverse} philosophy to work with the tidy data structures
  • build automatic workflow for analysis, feed different data sets.
